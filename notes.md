Rekomendasi Tech Stack "Irsyam Kidz Wear"

Untuk membangun toko online baju anak yang modern, responsif, dan mudah dikelola, berikut adalah rekomendasi teknologi yang bisa digunakan:

1. UI/UX Design
Design Tool: Figma (untuk prototyping dan desain antarmuka).
Iconography: Lucide React atau Phosphor Icons (gaya garis yang bersih dan modern).
Typography: Nunito atau Quicksand (font sans-serif yang bulat dan bersahabat untuk produk anak-anak).
2. Frontend (Antarmuka Pengguna)
Framework: Next.js (React). Memberikan performa cepat dengan Server-Side Rendering (SSR) yang bagus untuk SEO produk.
Styling: Tailwind CSS. Memungkinkan pengembangan UI kustom dengan cepat dan konsisten.
State Management: Zustand atau Redux Toolkit (untuk mengelola keranjang belanja).
Form Handling: React Hook Form dengan Zod untuk validasi.
3. Backend (Logika Bisnis & Data)
Database: PostgreSQL (Relasional, cocok untuk data produk, pesanan, dan pengguna).
ORM: Prisma (untuk interaksi database yang aman dan mudah).
API: Next.js API Routes atau Express.js (jika menggunakan backend terpisah).
Authentication: NextAuth.js (untuk login/register dengan email atau media sosial).
Payment Gateway: Midtrans atau Xendit (untuk memproses pembayaran online).
4. Deployment & Hosting
Frontend: Vercel (optimal untuk Next.js) atau Netlify.
Backend/Database: Railway, Supabase (database + auth), atau Render.
